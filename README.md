# Cloud Monitoring

A hands-on learning repository exploring cloud monitoring and observability using Prometheus and Grafana, alongside learning about New Relic.

## Overview

I created this repository while learning cloud monitoring concepts and following along with practical coding and setup exercises. It documents my hands-on exploration of monitoring tools used to track application metrics, visualize performance, and understand system health.

## Tools Covered

-   **Prometheus** — Learned how metrics are collected and stored as time-series data, along with the basics of querying metrics using PromQL.
    
-   **Grafana** — Explored visualizing metrics through dashboards and monitoring system performance.
    
-   **New Relic** — Learned about application performance monitoring and observability capabilities.
    

## What I Learned

-   Fundamentals of cloud monitoring and observability.
    
-   Collecting and querying metrics with Prometheus.
    
-   Visualizing metrics and creating dashboards with Grafana.
    
-   Understanding application performance and system health monitoring.
    
-   Exploring different approaches to observability using industry-standard tools.
